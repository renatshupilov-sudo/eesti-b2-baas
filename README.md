# База заданий «Eesti keel B2» — ежедневная практика к экзамену

Для человека, который уже прошёл курс B2 и хочет не растерять навык до экзамена Harno (eesti keele B2-taseme eksam). Задания на эстонском, пояснения на русском.

## Что внутри

| | |
|---|---|
| Уроков | 14 (двухнедельный цикл, затем повторяется) |
| Длительность урока | 31–40 минут |
| Заданий с автопроверкой | 300 (выбор ответа, верно/неверно, пропуски, аудио-диктант) |
| Письменных заданий | 4 (с образцом ответа и чек-листом) |
| Устная часть | не входит (по решению от 26.11.2026, можно добавить позже) |

**Каждый урок дня** содержит: новые слова → аудирование или аудио-диктант → основное задание в формате экзамена (чтение, аудирование, письмо или пробный экзамен) → мини-грамматика → самопроверка.

**Отдельные модули** собраны из тех же блоков: Sõnavara (слова), Kuulamine (аудирование), Grammatika, Lugemine (чтение), Kirjutamine (письмо).

**Словарь**: у каждого слова есть ссылка `dict` на словарь EKI Sõnaveeb, шаблон ссылки лежит в манифесте (`dictionary.urlTemplate`).

**Обратная связь на русском**: у каждого вопроса есть пояснение `explain_ru` (почему ответ такой, где он в тексте, какое правило). У блоков есть `advice_ru` — совет, если результат ниже 80%. Порог 60% показан как проходной балл экзамена.

## Экзамен (по данным Harno)

| Часть | Время | Баллы |
|---|---|---|
| Kirjutamine (письмо) | 80 мин | 25 |
| Kuulamine (аудирование) | 35–40 мин | 25 |
| Lugemine (чтение) | 70 мин | 25 |
| Rääkimine (речь) | ≈20 мин | 25 |

Сдано при 60 из 100 и если ни одна часть не 0. Письменная часть идёт в порядке письмо → аудирование → чтение, устная — через 15–20 минут после неё.

Источники: [Harno, Teabeleht tasemeeksami sooritajale 2024](https://harno.ee/sites/default/files/documents/2024-01/Teabeleht%20tasemeeksami%20sooritajale%202024_korras%20printimiseks.pdf), [Harno EIS — публичные задания](https://eis.harno.ee/publicitems), [Superprof: B2 eksami juhend](https://www.superprof.ee/blog/b2-keeleeksami-juhend/). Баллы по частям и форматы заданий взяты из вторичного источника (Superprof) — перед экзаменом сверьте с актуальной спецификацией на harno.ee.

## Структура файлов

```
content/
  manifest.json            ← точка входа: версия базы, список уроков, модули, сведения об экзамене
  lessons/d001.json … d014.json
  schema/lesson.schema.json    ← JSON Schema урока
  schema/manifest.schema.json  ← JSON Schema манифеста
index.html                 ← простой просмотрщик/прототип
tools/                     ← исходники уроков (Python) и сборка с проверкой по схеме
```

## Как приложение будет обновляться само

1. Приложение раз в день (или при открытии) скачивает `manifest.json` без кэша.
2. Сравнивает `contentVersion` и у каждого урока `version` + `sha256` с сохранёнными.
3. Докачивает только изменившиеся уроки, остальное берёт из памяти телефона — работает и без интернета.
4. Новые уроки просто добавляются в `lessons` манифеста; приложение их подхватит.

Чтобы это работало на телефоне, папку `content/` нужно положить на любой статический хостинг (например, GitHub Pages) — тогда у базы будет постоянный адрес.

## Как добавить или исправить урок

1. Отредактировать `tools/lessons_*.py` или `tools/extras.py` (у изменённого урока увеличить `version`).
2. Поднять `contentVersion` и дописать `changelog` в `tools/build.py`.
3. Запустить `python3 tools/build.py .` — сборка проверит все уроки по схеме и пересчитает хэши.

Все тексты учебные, имена и цифры в них вымышлены.
